How the two cores divide real-time work

gptimer drives a 64 kHz fast-tick interrupt on Core 1 that wakes dsp_task on Core 0 for every sample. Only one wake in four does the real DSP/RF work — that's the 16 kHz sample rate, Fs. Everything else on Core 1 (the ADC, loop(), serial, diagnostics) exists to stay out of that interrupt's way.
