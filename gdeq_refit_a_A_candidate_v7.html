A candidate gdeq refit for the a+A case

Not a new measurement: the "bare" (no gdeq) curve is reconstructed by subtracting the CURRENT gdeq's exactly-known analytic phase from the real ga_Trial2_TF.txt sweep (which had 'g'+shelf1+shelf2 all on). Validated: re-adding the current coefficients to this reconstruction reproduces Trial2's real measured curve almost exactly (self-consistency check, see notes).

Real improvement, but not the ~4x flattening the original gdeq fit achieved

Best achievable with 2 (or even 3-4) all-pass sections: 157.5 µs → 72.6 µs p-p (~2.2×) over 100-8000Hz, new coefficients a1=a2≈-0.1391. More sections barely help (3 sections: 71.3µs, 4 sections: 70.7µs) - this shape has a ceiling this filter type can't get past. The improvement is NOT uniform: it fixes 8000Hz dramatically (290.5→217.9µs) but actually ADDS 24-66µs of delay at 500-3100Hz relative to the current (mismatched) coefficients - a real trade-off between the two-tone fundamentals and the 8000Hz edge, not a free lunch. Mean delay barely changes (196.4→195.5µs), so '['/']' shouldn't need much re-tuning.

Why this is a trade-off, not a clean win

Shelf2's own delay curve has a sharp feature right near Nyquist (8000Hz) - a single-real-pole all-pass section's delay curve is smooth and can only produce one "hump" over the full band; cascading more of them barely adds capability here (each extra section converges to a near-identical, smaller coefficient - see the analysis notes) so there's a real ceiling on how well THIS filter type can track a curve shaped like the analog+shelf1+shelf2 combination. Flattening the whole band pulls delay away from 8000Hz and redistributes it into the 500-3100Hz region - exactly where the two-tone fundamentals and lower-order IMD products live - so whether this refit actually helps real IMD needs a bench test, not just a smaller p-p number. This is an estimate from a reconstructed curve, not a fresh 'g'-off/'a'+'A'-on measurement - recommended before fully trusting it, though the self-consistency check above is a strong sign the reconstruction is right.
